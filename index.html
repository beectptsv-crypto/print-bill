🖨️ Print Bridge (ພິມພາສາລາວໂດຍກົງ)

ສົ່ງບິນເປັນຮູບພາບໄປໃຫ້ເຄື່ອງພິມໂດຍກົງ (ຂ້າມບັນຫາ driver ບໍ່ຮອງຮັບພາສາລາວ). ຕ້ອງແລ່ນ python print_bridge.py ໄວ້ໃນເຄື່ອງກ່ອນ.

ຍັງບໍ່ໄດ້ເຊື່ອມຕໍ່ Print Bridge

ວິທີຕັ້ງຄ່າ: 1) ຕິດຕັ້ງ Python ແລ້ວຕິດຕັ້ງ library ດ້ວຍ pip install pywin32 2) ເປີດ Terminal ໄປຫາໂຟນເດີ້ນີ້ ແລ້ວແລ່ນ python print_bridge.py (ຄ້າງໄວ້ບໍ່ໃຫ້ປິດ) 3) ກັບມາໜ້ານີ້ ກົດ "🔄 ດຶງລາຍຊື່ເຄື່ອງພິມ" ແລ້ວເລືອກ "Xprinter POS-80".
